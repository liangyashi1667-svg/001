# CycleBoard · 项目周期多维管理

类似飞书项目的多维视图项目周期管理演示应用。

## 功能

- **项目空间**：多个项目切换，展示当前周期进度
- **多维视图**：表格 / 看板（拖拽改状态）/ 甘特时间线 / 日历
- **工作项**：需求、任务、缺陷、里程碑；状态、优先级、负责人、进度
- **筛选与分组**：搜索 + 表格按状态/负责人/优先级/类型分组
- **详情编辑**：侧栏编辑与新建工作项

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

## 技术栈

Vite + React + TypeScript
