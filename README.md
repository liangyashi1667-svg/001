# 留迹 · 会议遗留点跟进

根据会议纪要**链接**或**文档**，自动识别项目进展，并跟进每场会议的遗留点状态。

## 功能

- 粘贴公开网页 / Markdown 链接，或上传 `.md` / `.txt` / `.html` 文档
- 自动抽取：**项目名称**、**汇报人**、**议题**、**进展**、**遗留点状态**
- 列表页汇总各场会议待跟进数量；点击进入详情页查看与改状态
- 内置 4 份中文示例纪要，可一键演示

## 快速开始

```bash
npm install
npm start
```

浏览器打开 http://localhost:3790 ，点击「使用示例纪要」→「识别并进入跟进」。

本地命令行演示：

```bash
npm run analyze:demo
```

## 遗留点状态

| 状态 | 含义 | 纪要中的常见写法 |
|------|------|------------------|
| 未关闭 | 尚未处理 | `- [ ]` |
| 跟进中 | 正在推进 | `- [-]` 或文案含「跟进中」 |
| 已完成 | 已关闭 | `- [x]` 或文案含「已完成」 |

详情页可直接下拉修改状态，项目汇总会同步更新。

## API 摘要

- `POST /api/analyze` — 提交链接 / 文本 / 文件，返回 `sessionId` 与分析结果
- `GET /api/sessions/:id` — 获取会话汇总
- `GET /api/sessions/:id/meetings/:meetingId` — 会议详情
- `PATCH /api/sessions/:id/leftovers` — 更新遗留点状态
